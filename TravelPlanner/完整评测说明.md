# TravelPlanner 完整评测说明

## 完整评测 vs 简化评测

### 简化评测 (Simple Evaluation)
- **当前状态**: ✅ 可用
- **依赖**: 仅需 HuggingFace 数据集（自动下载）
- **功能**: 基本的约束检查，无需本地数据库
- **限制**: 无法验证计划中的地点、价格等是否真实存在

### 完整评测 (Full Evaluation)
- **当前状态**: ❌ 不可用（缺少数据库文件）
- **依赖**: 需要完整的本地数据库文件
- **功能**: 
  - 验证计划中的地点是否真实存在
  - 验证价格是否准确
  - 验证交通信息是否正确
  - 完整的约束检查（Commonsense + Hard Constraints）

## 完整评测所需文件

### 必需的文件结构

```
TravelPlanner/
├── database/
│   ├── flights/
│   │   └── clean_Flights_2022.csv          # 航班数据
│   ├── restaurants/
│   │   └── clean_restaurant_2022.csv       # 餐厅数据
│   ├── accommodations/
│   │   └── clean_accommodations_2022.csv   # 住宿数据
│   ├── attractions/
│   │   └── attractions.csv                 # 景点数据
│   └── background/
│       └── citySet_with_states.txt          # 城市-州映射
```

### 文件说明

1. **clean_Flights_2022.csv** (航班数据)
   - 字段: Flight Number, Price, DepTime, ArrTime, FlightDate, OriginCityName, DestCityName, Distance
   - 用途: 验证交通计划中的航班信息是否真实存在

2. **clean_restaurant_2022.csv** (餐厅数据)
   - 字段: Name, Average Cost, Cuisines, Aggregate Rating, City
   - 用途: 验证计划中的餐厅是否存在，价格、菜系是否正确

3. **clean_accommodations_2022.csv** (住宿数据)
   - 字段: NAME, price, room type, house_rules, minimum nights, maximum occupancy, review rate number, city
   - 用途: 验证住宿信息、房型、价格、规则是否符合要求

4. **attractions.csv** (景点数据)
   - 字段: Name, Latitude, Longitude, Address, Phone, Website, City
   - 用途: 验证景点是否存在，位置是否正确

5. **citySet_with_states.txt** (城市-州映射)
   - 格式: 每行 "城市名\t州名"
   - 用途: 验证城市路线是否合理

## 完整评测流程

### 1. 数据准备阶段
```bash
# 检查数据库文件
python TravelPlanner/check_database.py
```

### 2. 运行评测
```bash
# 使用完整评测
python TravelPlanner/run_eval_pipeline.py \
    --skip_generation \
    --input_file orchestrator/outputs/exports/travelplanner/submission_xxx.jsonl
```

### 3. 评测输出

完整评测会输出：
- **Delivery Rate**: 成功生成计划的比例
- **Commonsense Constraint Pass Rate**: 常识约束通过率
  - Within Current City (当前城市内)
  - Within Sandbox (沙盒范围内)
  - Reasonable City Route (合理城市路线)
  - Diverse Restaurants (餐厅多样性)
  - Diverse Attractions (景点多样性)
  - Non-conf. Transportation (交通一致性)
  - Minimum Nights Stay (最少住宿天数)
  - Complete Information (信息完整性)
- **Hard Constraint Pass Rate**: 硬约束通过率
  - Budget (预算)
  - Room Rule (房间规则)
  - Cuisine (菜系)
  - Room Type (房型)
  - Transportation (交通方式)
- **Final Pass Rate**: 最终通过率

## 路径问题说明

### 相对路径的使用

评测模块使用相对路径 `../database/...`，这意味着：
- 从 `TravelPlanner/evaluation/` 目录运行时，会查找 `TravelPlanner/database/`
- 从 `TravelPlanner/` 目录运行时，会查找 `TravelPlanner/../database/`（错误）

### 正确的运行方式

```bash
# 方式1: 在 TravelPlanner 目录运行
cd TravelPlanner
python run_eval_pipeline.py --skip_generation --input_file ...

# 方式2: 使用绝对路径（代码会自动处理）
python TravelPlanner/run_eval_pipeline.py --skip_generation --input_file ...
```
