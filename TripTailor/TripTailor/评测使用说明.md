# TripTailor 评测使用说明

## ⚠️ 重要说明

**完整评测要求**：评估任何AI模型时，必须完整运行所有 **703 条** 测试样本，不得只跑部分数据。只有完整评测才能反映模型的真实能力，部分测试会导致评估结果不准确、不可比较。

## 文件结构

```
TripTailor/TripTailor/eval/
├── simple_eval.py      # 主评测脚本 (严格版本) 
├── fact_checker.py     # 事实准确度验证模块
├── eval.py             # 原始完整评测脚本 (保留兼容)
├── prompt.py           # LLM 评测提示词
├── run_eval.sh         # 评测运行脚本
└── eval.sh             # 原始评测脚本
```

## 快速开始

### 基础评测 (完整703条样本)

```bash
cd TripTailor/TripTailor/eval

# 评估结果文件必须包含所有703条测试样本的生成结果
python simple_eval.py \
    --input_file ../outputs/deepseek_chat_direct_result.json \
    --plan_key deepseek_chat_direct \
    --info_file ../../data/infomation.json
```

> **注意**: `--input_file` 必须包含完整的 703 条样本结果，否则评测结果不具参考价值。

### 启用事实验证

```bash
python simple_eval.py \
    --input_file ../outputs/deepseek_chat_direct_result.json \
    --plan_key deepseek_chat_direct \
    --info_file ../../data/infomation.json \
    --enable_fact_check \
    --fact_check_samples 5
```

## 评测指标说明

### 基础指标

| 指标 | 说明 | 权重 |
|-----|------|------|
| **完整性** | 酒店/交通/行程/餐饮/景点是否完整 | 20% |
| **预算符合** | 总花费是否在预算内 | 15% |
| **餐费合理** | 餐费是否在指定范围 | 10% |

### 沙盒约束 (详细)

| 指标 | 说明 |
|-----|------|
| 酒店约束 | 酒店是否在给定列表中 |
| 交通约束 | 去程+返程交通是否在给定列表中 |
| 景点约束 | 所有景点是否在给定列表中 |
| 餐厅约束 | 所有餐厅是否在给定列表中 |
| **总体沙盒** | 以上全部通过 (权重 18%) |

### 多样性与时长

| 指标 | 说明 | 权重 |
|-----|------|------|
| 景点多样性 | 景点无重复 (严格模糊匹配) | 10% |
| 餐厅多样性 | 餐厅无重复 (严格模糊匹配) | 10% |
| 访问时长合理 | 景点访问时间符合参考时长 | 10% |

### 综合指标

| 指标 | 说明 | 权重 |
|-----|------|------|
| 可行性 | 完整性≥75% 且 满足沙盒约束 | 3.5% |
| 合理性 | 多样性+预算+餐费+时长 全部通过 | 3.5% |

### 事实准确度 (启用 --enable_fact_check)

| 指标 | 说明 | 权重 |
|-----|------|------|
| **事实准确度** | 景点/餐厅是否真实存在于正确城市 | **20%** |

## 参数说明

| 参数 | 说明 | 默认值 |
|-----|------|-------|
| `--input_file` | 输入文件路径 (必需) | - |
| `--plan_key` | 计划键名 (必需) | - |
| `--info_file` | 给定信息文件 | ../../data/infomation.json |
| `--output_file` | 输出结果文件 | - |
| `--detail` | 输出详细结果 | False |
| `--enable_fact_check` | 启用事实验证 | False |
| `--fact_check_samples` | 事实验证样本数 | 5 |
| `--search_engine` | 搜索引擎 | duckduckgo |

## 输入文件格式

```json
[
  {
    "pid": 1,
    "destination_city": "Xi'an",
    "departure_city": "Shanghai",
    "day": 4,
    "budget": 5000,
    "meal_price_range": [50, 150],
    "deepseek_chat_direct_plan_json": "{...}"
  }
]
```

## 严格性改进

相比原版本，严格版本增加了以下检查：

1. **完整性检查** - 增加到5项检查 (酒店、交通、行程、餐饮、景点)
2. **沙盒检查** - 完整检查去程+返程交通、所有景点、所有餐厅
3. **多样性检查** - 使用严格模糊匹配检测相似重复
4. **访问时长检查** - 验证景点访问时间是否合理
5. **事实验证** - 验证城市匹配，防止推荐错误城市的景点

## 验证完整性

运行评测前，请确认输入文件包含所有样本：

```bash
# 检查输入文件样本数量
python -c "import json; data=json.load(open('YOUR_RESULT.json','r',encoding='utf-8')); print(f'样本数量: {len(data)}')"
```

如果样本数量不是 703，需要重新完整运行 AI 生成流程。
